Hooks

Hooks 是在智能体事件触发时在 Gateway 网关内部运行的小脚本：例如 /new、/reset、/stop 等命令、会话压缩、Gateway 网关生命周期和消息流。

  1. 🚀 boot-md 启动钩子：开机自动加载 Markdown 模板、初始化会话文档
  2. 📎 bootstrap-extra-files 附加文件引导钩子：启动时自动加载额外配置 / 素材文件
  3. 📝 command-logger 指令日志钩子：记录所有你输入的命令、AI 返回内容，留存操作日志
  4. 🧹 compaction-notifier 存储压缩提醒钩子：会话缓存过载时自动弹窗提示清理冗余数据
  5. 💾 session-memory 会话内存持久钩子：跨会话保存对话上下文、记忆历史交互内容（示例提到的核心功能）

启动方式

  1. 终端
  2. WebUI
